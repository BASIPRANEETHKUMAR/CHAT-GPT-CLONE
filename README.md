💬 ChatGPT Clone

A modern, interactive web app that simulates a ChatGPT-style chatbot using HTML, CSS, and JavaScript.

It allows users to type messages and get simulated AI responses, with a clean chat interface and smooth animations.


---

🚀 Features

✅ User & Bot Messaging – Chat interface with distinct user and bot message bubbles.
✅ Simulated AI Responses – Bot replies with context-aware, pre-defined messages.
✅ Auto-scroll – Chat window scrolls automatically as new messages appear.
✅ Keyboard & Button Support – Press Enter or click Send to submit a message.
✅ Clean UI/UX – Modern, responsive layout with smooth animations.
✅ Offline Functionality – Works entirely in the browser; no backend required.


---

🧱 Tech Stack

HTML5 – Page structure and chat interface

CSS3 – Styling, animations, and responsive layout

JavaScript (ES6) – Dynamic chat logic and message handling

⚙ How to Run

1. Clone this repository



git clone https://github.com/<your-username>/ChatGPT-Clone.git

2. Open the project folder



cd ChatGPT-Clone

3. Run locally
Just open index.html in any modern browser — no server needed.

💡 Example Usage

1️⃣ Type a message in the input box (e.g., “Hello”)
2️⃣ Press Enter or click Send
3️⃣ The bot responds with a simulated reply (e.g., “Hey there 👋! How are you doing today?”)
4️⃣ Continue the conversation in the chat interface
